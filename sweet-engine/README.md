Sweet Engine v0.1
=================

Galaxy Signal Records
Windows x64 VST3

Sweet Engine is a focused stem enhancer for SYNTH and STRINGS tracks.

Modes:
SYNTH - definition, controlled low-mid cleanup, harmonic density and width.
STRINGS - smoother transients, stronger harshness control, silky air and body preservation.

Main controls:
CLEAN / TAME / DETAIL / SWEET / AIR / BODY / WIDTH / IMPACT

Secondary:
MIX / OUTPUT

Buttons:
AUTO / GOLDEN / MAX / DELTA / IMAGER / BYPASS

IMAGER:
Dedicated stereo enhancement switch. It expands upper stereo information while keeping low-frequency side energy controlled. WIDE SYNTH and CINEMATIC STRINGS enable it automatically.

Factory presets:
GOLDEN SYNTH
SWEET SYNTH
WIDE SYNTH
GOLDEN STRINGS
SILK STRINGS
CINEMATIC STRINGS

Install:
Copy the whole "Sweet Engine.vst3" bundle to:
C:\Program Files\Common Files\VST3\

Then rescan VST3 plugins in REAPER.
