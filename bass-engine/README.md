Bass Engine v0.2
================

Windows x64 VST3 low-end enhancement processor by Galaxy Signal Records.

Recommended use
---------------
Use one instance on the BASS track in BASS mode.
Use another instance on DRUMS or KICK in DRUM / KICK mode when the mix needs the combined low-end mass heard from bass + drums together.
Do not use this plugin on lead/backing vocals.

Modes
-----
BASS
- Stronger rumble and 180-320 Hz boom control.
- Keeps low-end weight while reducing uncontrolled mud.
- Smoother compression and stronger AUTO low-end protection.

DRUM / KICK
- Less infra-sub boost.
- More body, punch and transient impact.
- Faster control compression and tighter limiter release.
- Designed to make the kick/drum layer contribute to the perceived "fatness" without only adding sub.

Main controls
-------------
SUB       - deepest low foundation
WEIGHT    - main body and mass
DRIVE     - saturation / thickness
PUNCH     - transient impact
TIGHT     - rumble and low-mid control
HARMONICS - upper bass/kick harmonics and speaker translation
LOUD      - density, soft clipping and final limiting drive

Secondary
---------
CLARITY / MIX / OUTPUT

Buttons and menu
----------------
AUTO   - recalls the Golden preset for the current mode and enables adaptive low-end protection
GOLDEN - recalls Golden for BASS or DRUM / KICK
MAX    - unlocks intentionally aggressive processing ranges
BYPASS - instant before/after comparison

Top menu:
< / >  - previous / next factory preset
PRESET - open preset list
SAVE   - save a temporary USER snapshot
A/B    - compare two complete plugin states
RESET  - return to Golden for the current mode
MENU   - Golden, USER snapshot and About

Install
-------
Copy the whole "Bass Engine.vst3" bundle to:
C:\Program Files\Common Files\VST3\

Then rescan VST3 plugins in REAPER.
