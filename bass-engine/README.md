Bass Engine v0.1
================

Windows x64 VST3 dedicated bass-track processor.

Recommended use:
Insert Bass Engine directly on the BASS track.
Do not use it on lead/backing vocals.

Main controls:
SUB       - deepest low foundation
WEIGHT    - body and mass
DRIVE     - saturation / thickness
PUNCH     - attack and transient impact
TIGHT     - rumble and low-mid control
HARMONICS - upper bass harmonics / audibility
LOUD      - density, soft clipping and final limiter drive

Secondary:
CLARITY / MIX / OUTPUT

Buttons:
AUTO   - recalls GOLDEN and enables adaptive low-end protection
GOLDEN - recalls the starting preset
MAX    - intentionally allows more aggressive low-end and drive
BYPASS - bypass

Golden start:
SUB 52 / WEIGHT 62 / DRIVE 42 / PUNCH 48 / TIGHT 50 / HARMONICS 44 / LOUD 30
CLARITY 45 / MIX 100 / OUTPUT 0 dB

Install:
Copy the whole "Bass Engine.vst3" bundle to:
C:\Program Files\Common Files\VST3\

Then rescan VST3 plugins in REAPER.
