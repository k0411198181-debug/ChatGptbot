# KG Vocal Engine v0.3 TEST

Windows x64 / VST3 / REAPER oriented vocal processor.

Main macros: CLEAN, BODY, AIR, SIZE, WIDTH, DELAY, SPACE.
Secondary: INPUT, THROW, MIX, OUTPUT. Buttons: AUTO, LIVE, SYNC, BYPASS.

Default KG LIVE VOCAL calibration is based on the dry phone test vs. processed Live On reference.

Delay Throw is a VST3 automatable parameter. In REAPER, display the automation envelope for KG Vocal Engine: Delay Throw and raise it only on words where the delay tail should bloom. Base DELAY stays active throughout the vocal.

Install: copy the whole KG Vocal Engine.vst3 folder to C:\Program Files\Common Files\VST3\ then REAPER > Preferences > Plug-ins > VST > Re-scan.

This is a TEST build. Compare against bypass and keep output conservative.
