KG Human Engine v0.1
====================

Galaxy Signal Records
Windows x64 VST3

Purpose
-------
KG Human Engine is a creative "organic feel" processor for instrument stems.
It is NOT designed to evade or defeat AI-detection systems.

It adds controlled musical variation:
- micro-dynamic movement
- transient articulation
- slow phrase-scale flow
- subtle tonal saturation
- stereo breathing and width

Modes
-----
MELODIC
For piano, keys, strings, guitars and melodic stems.

RHYTHMIC
For rhythmic guitars, percussion and pulse-driven parts.

ATMOSPHERE
For pads, long synth layers, cinematic beds and sustained textures.

Main controls
-------------
HUMAN  - master intensity of organic variation
FEEL   - small micro-dynamic movement
ATTACK - transient articulation
FLOW   - slower phrase-level movement
DRIFT  - speed/depth source for slow organic variation
COLOR  - gentle harmonic coloration
MOTION - stereo breathing
WIDTH  - overall stereo width

Secondary
---------
MIX / OUTPUT

Buttons
-------
AUTO / GOLDEN / MAX / DELTA / BYPASS

Factory presets
---------------
GOLDEN HUMAN
MELODIC SOUL
RHYTHMIC FEEL
ATMOSPHERE FLOW
SUBTLE LIFE

Install
-------
Copy the whole "KG Human Engine.vst3" bundle to:
C:\Program Files\Common Files\VST3\

Then rescan VST3 plugins in REAPER.
