KG Sketch Piano v0.3
====================
Windows x64 VST3 instrument by KG Music Records.

Designed for REAPER and external MIDI keyboards including Arturia controllers.
32 voices, CC64 sustain, CC1 modulation, pitch bend, project state saving.
Modes: GRAND / SOFT / LOFI / PAD.
Controls: CHARACTER / BRIGHT / BODY / FELT / WIDTH / SPACE / DAMP / ATTACK / RELEASE / VEL / MIX / OUTPUT.

Install the whole `KG Sketch Piano.vst3` bundle to:
C:\Program Files\Common Files\VST3\
Then rescan VST3 in REAPER.
